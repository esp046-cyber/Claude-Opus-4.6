🔧 Troubleshooting Guide

Solutions to common issues and ways to get better responses from Claude Opus 4.6

❗ Common Error Messages

⚠️ "Error: Rate Limit Exceeded"

Cause: Too many requests in a short time period

Solutions:

  • Wait 60 seconds before sending another message
  • Upgrade to Claude Pro for higher rate limits
  • Combine multiple questions into one message
  • For API users: implement exponential backoff

⚠️ "Context Length Exceeded"

Cause: Conversation or input exceeds 200K token limit

Solutions:

  • Start a new conversation to clear context
  • Summarize previous discussion and continue
  • Break large documents into smaller chunks
  • Remove unnecessary uploaded files

⚠️ "File Upload Failed"

Cause: File size too large or unsupported format

Solutions:

  • Compress large files (limit: 10MB per file)
  • Convert to supported formats (PDF, TXT, DOCX, images)
  • Split large files into smaller parts
  • Use image compression for screenshots

⚠️ "Code Execution Timeout"

Cause: Code took too long to run (>60 seconds)

Solutions:

  • Optimize code for better performance
  • Process data in smaller batches
  • Avoid infinite loops or heavy computations
  • Request code without execution for complex tasks

❓ Frequently Asked Questions

Why did Claude refuse my request?

Common Reasons:

  • Safety: Request involved harmful content, malware, or illegal activities
  • Privacy: Asked to identify people from photos without consent
  • Copyright: Requested copyrighted material (song lyrics, books)
  • Uncertainty: Claude wasn't confident it could help accurately

What to do: Rephrase your request, explain your legitimate use case, or ask for alternatives Claude can provide.

How can I improve Claude's responses?

Better Prompting Techniques:

  • Be specific about format, length, and style
  • Provide examples of what you want
  • Break complex tasks into steps
  • Ask Claude to "think step-by-step"
  • Specify tone (professional, casual, technical)
  • Give context about your audience or purpose
  • Request revisions with specific feedback
"Explain quantum computing for a business executive (non-technical). Use analogies, keep it under 200 words, focus on practical applications."
Why are responses sometimes inconsistent?

AI models can produce varied outputs. To get more consistent results:

  • Use temperature setting 0.0 (API only) for deterministic output
  • Provide detailed constraints and requirements
  • Use the same conversation thread for related tasks
  • Request specific formats (JSON, tables, lists)
  • Give examples of desired output style
Why can't Claude access certain websites?

Web search has limitations:

  • No access to paywalled content (NYT subscriptions, etc.)
  • Can't bypass login-required pages
  • Some sites block automated access
  • Real-time data may have slight delays

Alternative: Copy and paste content directly into the conversation or upload as a file.

⚡ Performance Issues & Solutions

🐌 Slow Response Times

Possible Causes & Fixes:

  • Long prompts: Claude processes entire context - be concise
  • Heavy computation: Complex code execution takes time
  • Web search: Searching multiple sources adds latency
  • Peak hours: Try during off-peak times
  • Solution: Switch to Sonnet 4.5 or Haiku 4.5 for faster responses

🔄 Claude Seems to Forget Context

Solutions:

  • Explicitly reference earlier parts: "As we discussed earlier..."
  • Summarize key points before asking follow-ups
  • Use artifacts for important information you'll reference
  • Enable conversation memory in settings
  • Keep critical info in the recent messages

📊 Visualizations Not Rendering

Troubleshooting:

  • Ensure artifacts feature is enabled in settings
  • Refresh the page if visualization appears blank
  • Try different chart library (Chart.js, Plotly, Recharts)
  • Check browser console for JavaScript errors
  • Request HTML artifact instead of React if issues persist

💾 Lost Work or Conversation

Prevention & Recovery:

  • Important work: Download artifacts immediately
  • Enable "Search past chats" to find old conversations
  • Use Projects feature for ongoing work
  • Copy critical responses to external storage
  • Browser crash: Check conversation history after restart
